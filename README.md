# Henry Brandt – Portfolio

A personal portfolio website built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive design with mobile navigation
- Bilingual support (Swedish/English) with localStorage
- Contact form with EmailJS integration
- Live weather display via OpenWeatherMap API
- Smooth scroll and fixed navbar

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## Setup

Clone the repo and open `index.html` in your browser. No build step required.

Add your API keys in `app.js`:
- `EMAILJS_PUBLIC_KEY`
- `OPENWEATHERMAP_API_KEY`

## Pages

- `index.html` – Main portfolio (about, projects, contact)
- `resume.html` – CV page
